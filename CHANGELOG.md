# Changelog

## 1.0.0 — 2026-11-15

- Собственное ядро CMS с конфигурируемыми типами, таксономией, ревизиями и миграциями SQLite.
- Панель с ролями, модерацией, пакетными операциями, медиа, аудитом и статистикой.
- Публичный портал, две темы, экранирование, REST API и SEO.
- Харнесс с правилами, ограниченными командами, SPEC, ADR, техническими трассами и воспроизводимыми проверками.

Учебный локальный релиз. Приёмка преподавателем и живая защита выполняются отдельно.
