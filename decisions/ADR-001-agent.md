# ADR 001 Выбор агента

Статус: рабочее решение реализации, 15.11.2026.

## Контекст
Один студент, учебные данные и ограниченный срок. Нужны правила в репозитории, ограничение записи, тесты и экспорт действий. Матрица отражает документацию, проверенную 15.11.2026; абсолютные цены не сравниваются без одинакового тарифа и модели.

| Критерий | OpenAI Codex | Claude Code | Aider |
| --- | --- | --- | --- |
| Правила проекта | AGENTS.md и навыки | CLAUDE.md и настройки | Файлы соглашений через read |
| Разрешения | Среда исполнения, sandbox и approvals | allow/ask/deny и sandbox | Требует внешней изоляции для shell; не считать эквивалентом sandbox |
| Трассы | Журнал сессии; в этой работе экспорт JSONL | Локальная история сессий | input/chat/llm history files |
| Инструменты | Команды, файлы, делегирование | Команды, файлы, hooks | Git, редактирование, lint/test |
| Стоимость | Зависит от доступа и выбранной модели | Зависит от подписки или API | Оболочка открытая; модель оплачивается отдельно или локальная |
| Доступность на стенде | Уже предоставлен в текущей среде | Не устанавливался и не испытывался | Не устанавливался и не испытывался |

Выбран Codex, поскольку он доступен в среде выполнения и позволяет проверить решение без настройки второго аккаунта. Это решение о воспроизводимости данной работы, а не рейтинг качества моделей. Альтернативы не отвергнуты по результатам бенчмарка, которого здесь не было.
