# SPEC 02 Интерфейсы и шаблоны

Контекст: SPEC 00 и SPEC 01. Собственная WSGI-панель без автоадминки.

Требования: /login, /logout, /admin, формы создания и редактирования каждого типа, модерация, откат ревизий, фильтры, поиск и пакетная операция. Автор видит и изменяет свои материалы; редактор и администратор модерируют. Администратору доступны статистика и журнал действий. Каждая POST-форма имеет CSRF-токен. Публичная часть выдаёт только published. API /api/materials имеет page и page_size с верхней границей, фильтры category/tag/type. Шаблонный слой изолирован, поддерживает две темы, наследование и partial, все пользовательские строки экранируются по умолчанию.

Приёмка: 10 и более проверок роль/операция, минимум 3 HTTP-сценария, включая вход и CRUD, публикацию и API, XSS и запрет доступа. Проверяются sitemap и метатеги. Действия через браузер и скриншоты фиксируются только после запуска настоящего приложения.
