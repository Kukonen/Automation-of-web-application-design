# SPEC Номер и название

## Контекст
Зачем нужна задача; какие ADR, схемы, интерфейсы и тесты прочитать.

## Требования
Наблюдаемое поведение; входы, выходы и ошибки; разрешённые файлы; ограничения доступа и данных.

## Критерии приёмки
Проверяемые сценарии с конкретными входами и ожидаемыми результатами. Команда верификации. Какие результаты приложить к ревью.

## Размер порции
Одна проверяемая возможность; ориентир до 300 строк изменения без механически сгенерированных данных. Превышение требует разбиения по инвариантам, а не по произвольному числу строк.

## Решение ревью
Принять / исправить / отклонить. Основание и ссылка на evidence. Решение агента является технической рекомендацией; окончательная приёмка принадлежит студенту.
